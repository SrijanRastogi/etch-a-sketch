# Etch-a-Sketch

A browser-based Etch-a-Sketch drawing application built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## Features

- 16 × 16 grid generated dynamically with JavaScript.
- Change the grid size from 1 × 1 up to 100 × 100.
- Grid maintains the same overall drawing area when resized.
- Draw by hovering over the grid squares.
- Random RGB color generated for each square.
- Repeatedly hovering over a square progressively darkens its color.
- Uses Flexbox to create the grid layout.
- Input validation for grid size.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- DOM Manipulation
